# SnipKeep

macOS 截图工具，基于 ScreenCaptureKit 构建，提供丰富的截图、标注和长截图功能。

## 功能

- **区域截图** — 拖拽选择区域，支持拖拽移动和拖拽调整大小
- **窗口截图** — 鼠标悬停高亮窗口，点击即可截取
- **标注工具** — 箭头、文字、编号、马赛克、矩形、椭圆、高亮，支持 9 种颜色
- **长截图** — 手动滚动浏览器页面即时拼接，自动跳过重复内容、固定导航栏和底部悬浮控件
- **贴图钉** — 截图后固定到屏幕上，可拖拽位置
- **全局快捷键** — 可自定义快捷键，一键唤起截图
- **开机自启** — 支持注册为登录项
- **自定义保存路径** — 设置默认保存目录，截图自动保存

## 系统要求

- macOS 14 (Sonoma) 或更高版本
- 需要屏幕录制权限（系统设置 → 隐私与安全性 → 屏幕录制）

## 构建

使用 `build.sh` 脚本一键构建并安装到 `/Applications`：

```bash
# 构建 release 版本（默认）
./build.sh

# 构建 debug 版本
./build.sh debug
```

脚本会自动编译、打包 `.app` bundle 并安装到 `/Applications`。安装后可从启动台或以下命令启动：

```bash
open "/Applications/SnipKeep.app"
```

## 使用

运行后程序驻留在菜单栏，点击菜单栏图标或按下快捷键开始截图。

选定区域后会显示精简工具条：点击「复制」确认复制到剪贴板，或点击「固定」将截图贴在屏幕上；「标注」展开绘图工具，「长截图」进入滚动截图，「更多」包含保存和取消。标注时按 Return/Enter 也可确认复制。

首次使用需授予屏幕录制权限。

## 快捷键

默认快捷键为 `⌥⇧5`，可通过菜单栏「设置快捷键」自定义。
