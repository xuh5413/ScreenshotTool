# 剪贴板管理功能设计

## 目标

在现有 macOS 截图工具内增加完整的本地剪贴板历史管理，支持文字、链接、图片和文件。用户可以通过全局快捷键或菜单栏入口打开同一个悬浮面板，搜索和预览历史项目，并将选中项目恢复到系统剪贴板。

功能只在本机保存数据，不自动粘贴，不申请辅助功能权限，也不提供云同步。

## 使用流程

1. 应用常驻运行并监听系统剪贴板变化。
2. 支持的非敏感内容写入本地历史；重复内容更新时间并移到顶部。
3. 用户按 `⌘⇧V`，或从菜单栏选择“剪贴板历史…”，打开历史浮窗。
4. 用户可搜索、筛选、预览、收藏或删除项目。
5. 用户按 `Enter`、双击项目或点击“复制”，将该项目恢复到系统剪贴板并关闭浮窗。

## 架构

### ClipboardMonitor

- 通过 `NSPasteboard.general.changeCount` 监听变化。
- 在串行队列上读取和规范化剪贴板内容。
- 支持文字、URL、图片和文件 URL。
- 文件优先按文件类型解析，普通 URL 按链接解析，其余字符串按文字解析。
- 记录内容写入时的前台应用名称和 bundle identifier。
- 应用自己恢复历史项目时设置抑制标记，避免重新生成重复事件。
- 忽略系统或密码管理器标记为隐藏、临时、自动生成的内容。

### ClipboardStore

- 使用系统 SQLite 保存元数据、文字内容和搜索字段，不引入第三方依赖。
- 图片转为 PNG 文件，保存在 Application Support 的资源目录中；数据库只保存相对路径。
- 文件项目只保存原始 URL，不复制文件内容。
- 所有写入通过单一存储队列串行执行。
- 数据库和资源文件更新采用临时文件加原子替换，避免异常退出留下半写入文件。
- 使用规范化内容的 SHA-256 作为去重键。

### ClipboardPanelController

- 管理一个可成为 key window 的无标题 `NSPanel`。
- 全局快捷键和菜单栏入口共用同一个面板实例。
- 负责查询、筛选、键盘导航、鼠标操作、预览和恢复动作。
- 面板失去焦点、用户按 `Esc` 或点击关闭按钮时关闭。

### PrivacyFilter

- 检查 Concealed、Transient 和 AutoGenerated 等 pasteboard 类型。
- 根据用户配置的 bundle identifier 排除指定应用。
- 超过单条大小限制的内容不写入历史。
- 不进行网络请求，不将历史写入 iCloud 容器。

## 数据模型

`ClipboardItem` 包含：

- `id`：稳定 UUID。
- `kind`：text、link、image、files。
- `contentHash`：规范化内容的 SHA-256。
- `plainText`：文字、链接或用于搜索的文件名。
- `assetPath`：图片资源的相对路径。
- `fileURLs`：文件 URL 列表。
- `sourceAppName` 和 `sourceBundleID`。
- `createdAt`、`updatedAt`、`lastRestoredAt`。
- `isFavorite`。
- `byteSize`。

相同 `contentHash` 再次出现时更新来源、时间和排序位置，不新增重复记录。收藏状态保留。

## 浮窗界面

浮窗默认约 640 × 440，使用双栏布局：

- 顶部提供搜索框和“全部、文字、图片、文件、收藏”筛选。
- 左侧列表显示类型图标、摘要、来源应用和复制时间。
- 右侧显示完整文字、链接、图片缩略图或文件列表预览。
- 底部或预览区提供“复制”主操作。

鼠标操作：

- 单击项目：选中并预览。
- 双击项目：恢复到剪贴板并关闭浮窗。
- 点击星标：收藏或取消收藏。
- 点击删除：删除当前项目。
- 右键菜单：复制、收藏或删除。

键盘操作：

- `↑ / ↓`：切换项目。
- `Enter`：恢复到剪贴板并关闭。
- `Space`：展开预览。
- `Delete`：删除当前项目。
- `⌘F`：聚焦搜索框。
- `Esc`：关闭浮窗。

## 菜单与快捷键

- 默认全局快捷键为 `⌘⇧V`。
- 现有菜单栏菜单增加“剪贴板历史…”项目。
- 快捷键和菜单项目都打开同一个 `ClipboardPanelController`。
- 后续可在现有快捷键设置窗口中增加剪贴板快捷键配置，本期先使用默认值并处理注册冲突。

## 保留与容量策略

- 默认最多保留 500 条非收藏项目。
- 非收藏项目默认保留 30 天。
- 资源目录默认上限 1 GB。
- 达到数量、时间或磁盘限制时，按最旧顺序删除非收藏项目。
- 收藏项目不因时间和数量清理；若收藏资源已达到磁盘上限，则停止记录新的大资源并在界面提示。
- 删除图片项目或清空历史时同步删除对应资源文件。
- 文件 URL 失效时保留记录并在预览中显示“文件不存在”，允许用户删除。

## 内容限制

- 文字和链接单条最多 1 MB。
- 图片编码后的单条资源最多 40 MB。
- 文件项目只保存 URL 和元数据，不计算文件本体大小。
- 无法解析、无法编码或超过限制的内容跳过记录，不影响后续监听。

## 恢复规则

- 文字按 `.string` 写回。
- 链接同时写入 URL 和字符串表示。
- 图片写入 PNG/TIFF 兼容表示。
- 文件写回文件 URL 列表。
- 每次恢复前清空系统剪贴板，并在写入成功后更新 `lastRestoredAt`。
- 写入失败时保留浮窗和选中状态，并显示简短错误信息。

## 错误处理

- 数据库初始化失败时禁用历史功能，但不影响截图功能。
- 单条读取或写入失败只跳过该项目并记录日志。
- 资源文件缺失时显示占位预览。
- 全局快捷键注册冲突时保留菜单栏入口，并在设置中提示冲突。
- 数据库清理和资源清理由后台队列执行，完成后刷新界面。

## 测试策略

### 单元检查

- 各内容类型的规范化和哈希稳定性。
- 重复内容更新排序且不新增记录。
- 500 条、30 天和 1 GB 清理策略。
- 收藏项目免于常规清理。
- Concealed、Transient、排除应用和大小限制过滤。
- 各类型恢复为正确的 pasteboard 表示。
- 自恢复抑制逻辑不会产生重复记录。

### 集成检查

- 使用独立 `NSPasteboard` 验证文字、链接、图片和文件的捕获及恢复。
- 验证数据库与图片资源的创建、删除和异常恢复。
- 验证快捷键和菜单栏入口打开同一个面板。

### 界面检查

- 鼠标单击预览、双击恢复、收藏、删除和右键菜单。
- 键盘导航、搜索、筛选和关闭行为。
- 长文字、大图、多个文件和失效文件路径的布局。

## 不在本期范围

- 自动发送 `⌘V`。
- 跨设备或云同步。
- 富文本编辑。
- OCR、翻译或内容总结。
- 独立 Helper 进程。
- 将文件内容复制到历史资源目录。
